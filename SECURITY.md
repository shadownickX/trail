# Security policy

TRAIL is designed as a read-only research product. It should not request wallet seed phrases, private keys, transaction approvals, or custody permissions.

## Reporting a vulnerability

Do not open a public issue containing exploitable details, credentials, private endpoints, or user data. Contact the repository owner privately through the security-reporting channel configured for the project.

Until a private contact address is published, avoid sharing sensitive reproduction material in this repository.

## Supported surface

The current repository contains a product specification and visual prototype. Security support expands when executable components are introduced.
