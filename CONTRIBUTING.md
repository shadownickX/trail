# Contributing to TRAIL

TRAIL is built around reproducible observations. Contributions are welcome when they improve the clarity, coverage, or verifiability of the research flow.

## Before opening a pull request

- describe the user problem being solved;
- keep relationship labels factual;
- include fixtures or references for classification changes;
- label invented examples as illustrative;
- do not add private keys, wallet secrets, or paid-provider credentials;
- avoid `SAFE`, guaranteed-return, or identity claims that the data cannot prove.

## Commit style

Use short imperative subjects:

```text
Add next-purchase classifier
Document shared-funding limitations
Improve rotation table coverage state
```

## Pull requests

Explain what changed, how it was checked, and which evidence boundary may be affected. Visual changes should include a before-and-after capture.
